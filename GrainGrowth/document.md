# Grain Growth (Allen-Cahn model)
## Introduction
This script main.py is applied to simulate the microstructural evolution of polycrystaline texture.

## Model
The simulation seetings and parameters refers to the Part1: Simulation settings.

There is only one composition in the simulation.
In a 2D simulation frame, the intial microstructure is a Voronoi-strcture, similar with the polycrystal structure in metal or alloy.
